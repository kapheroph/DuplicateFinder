# Bill's Duplicate Finder v1.0 - Quick Start

Bill's Duplicate Finder helps you find duplicate or very similar photos without permanently deleting anything.

## The important bit

**The program never permanently deletes your photos.**

When you choose to remove a copy, it is moved into a `DuplicateFinder_Quarantine` folder. You can restore it later with Quarantine Manager.

## Getting started

1. Double-click `Bill's Duplicate Finder.exe`.
2. Click **Choose Folder** and select the folder containing your photos.
3. Leave **Include subfolders** unticked if you only want to check that one folder. Tick it if you also want folders inside it checked.
4. Click **Scan**.

Scanning only looks at your pictures. It does not move, rename, edit, or delete them.

## What the match types mean

### Exact

These are completely identical files. Either copy is safe to keep.

### Same pixels

The visible picture is exactly the same even though the file itself may contain different metadata or compression. Either image is visually safe to keep.

### Similar

These appear to be the same or closely related photo but are not identical. One may be cropped, brighter, darker, sharper, or a different size.

Read the notes below each image. When one picture has a clear technical advantage, the program marks it **Suggested keep** and explains why. This is only a suggestion - keep the picture you actually prefer.

## The buttons under each photo

- **Keep** - leave the photo where it is.
- **Ignore** - do nothing with that photo during this review.
- **Quarantine** - mark the photo to be moved safely out of the folder when you confirm.

Nothing moves until you click **Move Selected to Quarantine** and confirm.

## Getting a photo back

1. Choose the original photo folder.
2. Click **Quarantine Manager**.
3. Select one or more pictures.
4. Click **Restore Selected**, or use **Restore All**.

If a file with the same name already exists, the program will not overwrite it. The restored copy receives a new name instead.

## Best rule if you are unsure

**Keep the photo. You can always come back later.**
